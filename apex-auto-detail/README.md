# Apex Auto Detail

A fictional mobile detailing business, built with semantic HTML, CSS, and vanilla JavaScript. Open `dist/index.html` directly, or serve `dist` using any static web server. No build or dependencies required.

Edit content in `dist/index.html`, design tokens and responsive layouts in `dist/styles.css`, and interactions in `dist/script.js`.

## Before a real launch

Replace sample prices, service area, testimonials, contact information, hours, and social platform links with verified business details. The quote form validates inputs and prepares a copyable request locally. It sends and stores nothing. Connect a backend and privacy notice before collecting leads. The gallery's before effect is simulated and explicitly labeled.
